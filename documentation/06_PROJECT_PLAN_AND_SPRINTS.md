# Project Development Plan & 8-Week Sprint Roadmap

Please refer to the primary Sprint Plan document located at:
**[docs/PROJECT_PLAN_AND_SPRINTS.md](../docs/PROJECT_PLAN_AND_SPRINTS.md)**

### Sprint Breakdown
- **Sprint 1 (Weeks 1-2):** Requirements Engineering, 3NF Database Design, System Architecture & Stage 1 Sign-off.
- **Sprint 2 (Weeks 3-4):** Security Infrastructure, Authentication (Bcrypt), RBAC, SaaS Layouts & Student Fault Reporting with Multi-Image Uploads.
- **Sprint 3 (Weeks 5-6):** Technician Work Queue, Status State Machine (`Pending` -> `Assigned` -> `In Progress` -> `Resolved` -> `Closed`), Technical Notes, and Student Reopen Loop.
- **Sprint 4 (Weeks 7-8):** Admin Control Center, Chart.js Analytics, Notification Engine (In-App, SMTP Email, Mock SMS), Security Hardening, Automated Testing & Final Presentation.
